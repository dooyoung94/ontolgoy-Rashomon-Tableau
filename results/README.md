# 결과 사용 기준

현재 논문의 주 결과는 아직 새로 산출하지 않았다.

앞으로 결과로 인정하는 실험은 다음 조건을 모두 만족해야 한다.

1. 수집 데이터는 그대로 유지한다.
2. 노드는 제거하지 않는다.
3. 기존 토폴로지 관계만 20%, 40%, 60% 제거한다.
4. 제거된 관계를 모델에 표시하지 않는다.
5. 복원 방법은 S0~S4로 비교한다.
6. 실제 제거한 관계를 기준으로 정확도, 재현율, F1을 계산한다.
7. 이후 관계가 빠진 토폴로지, 복원한 토폴로지, 완전한 토폴로지의 장애 원인 분석 성능을 비교한다.

이전의 수집 단서 삭제, 정상/장애 구간 일치도, 장애 인과 라벨 마스킹 결과는 주 결과로 사용하지 않는다.
